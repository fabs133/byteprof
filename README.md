# byteprof

Code, scripts and findings log behind the paper *The Byte Tax: Decode Speed of Byte-Level Language Models on a
Consumer GPU*. The repository holds `byteprof`, a harness that times the components of byte-level generation
(local encoder, boundary predictor, global transformer, local decoder, LM head) for Bolmo 1B and its source model
OLMo 2 1B, plus the optimized decode loops, kernels and drafting experiments from 13 hypothesis-driven studies.
`FINDINGS.md` is the full log of those studies, with the hypotheses as they were written before each measurement.

DOI: [10.5281/zenodo.23924377](https://doi.org/10.5281/zenodo.23924377)

## Layout

```
byteprof/            package: harness, optimized decode loops, drafting, quantization, kernels
tools/               Python tools used by the studies (reports, benchmarks, config generators)
tests/               tests
configs/  prompts/   model and run configs (TOML), fixed prompt sets
scripts/<study>/     the run_*.sh scripts, grouped by study (see scripts/README.md)
notebooks/colab/     Colab notebook (generated by tools/build_colab_notebook.py) and a short README
notes/               design notes (decode loop of Bolmo)
paper/               LaTeX source (main.tex, references.bib) and main.pdf
FINDINGS.md          full findings log
CLAUDE.md            measurement runbook
pyproject.toml  requirements.txt  .gitignore
```

`results/` (raw results) and `archive/` are git-ignored and not part of the repository.

## Setup

Windows (PowerShell), as used for all reported numbers:

```powershell
py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1
pip install torch --index-url https://download.pytorch.org/whl/cu124   # pick the wheel matching your driver
pip install -r requirements.txt
```

Linux:

```bash
python3.11 -m venv .venv
source .venv/bin/activate
pip install torch --index-url https://download.pytorch.org/whl/cu124
pip install -r requirements.txt
```

`requirements.txt` installs `triton-windows` on Windows only; `xlstm==2.0.6` and `mlstm_kernels==2.0.6` are pure-Python
wheels. The model card of Bolmo was tested with Python 3.11 and transformers 4.57.3, which this repository keeps.
Note that the study scripts under `scripts/` call `.venv/Scripts/python.exe` (the Windows venv layout); on Linux, adjust
that path.

## Reproduce

```powershell
python -m pytest -q
python -m byteprof discover --config configs/bolmo-1b.toml     # prints and saves the module tree
python -m byteprof profile  --config configs/bolmo-1b.toml     # one profile run, writes results/<timestamp>/
```

The studies are in `scripts/<study>/`; `scripts/README.md` lists what each one ran and which section of
`FINDINGS.md` it feeds. Stop other GPU applications (for example Ollama) before measuring.

## Results

The raw results (~1.1 GB) are released with the Zenodo record, not in git.

## Hardware

All reported numbers come from one RTX 3060 Ti (8 GB) on Windows, at batch size 1, with greedy decoding and a fixed
seed. Clocks drift on this machine, so repeated runs can differ by a few percent; the studies rerun any pair that
differs by more than 5%.
